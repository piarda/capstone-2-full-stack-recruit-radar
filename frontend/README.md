# Frontend - Recruit Radar

This is the frontend application built with React to interact with the Recruit Radar API.


## Technologies:
- React (JavaScript)
- useEffect/useState
- CSS
- HTML


## Setup Instructions:
1. Navigate to the frontend folder:
   cd frontend

2. Install dependencies:
    npm install

3. Start the development server:
    npm run dev

The app will run on http://localhost:5173/


## Core Functionality:
- View a paginated list of candidates
- Search candidates by name
- Add, update, and archive/unarchive candidates
- Add, edit, and view follow-ups
- Update candidate stages
- Input validation for name, email, and phone
